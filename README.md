# 📝 Exam Management System

A web-based **Exam Management System** developed using **JSP, HTML, CSS, JavaScript, Java Servlets, and Apache Tomcat**.

The system helps manage examinations, students, subjects, questions, and results through an easy-to-use web interface.

---

## 📌 Project Overview

The Exam Management System is designed to simplify and manage the examination process digitally.

It provides a centralized platform for managing student information, exam details, questions, and examination results. The system reduces manual work and makes the examination process more organized and efficient.
